# Student Task Manager App Plan

## App Name
Student Task Manager

## Purpose
This app helps students manage daily tasks, assignments, and study goals.

## Target Users
Students who want to organize their study work.

## Main Features
1. Add task
2. View task list
3. Mark task as completed
4. Delete task
5. View student profile

## Screens
1. Home Screen
2. Task List Screen
3. Add Task Screen
4. Profile Screen

## User Flow
Open app → View home screen → Add task → View task list → Mark complete or delete task.

## Native vs Hybrid vs Cross-Platform
Native apps are built separately for Android and iOS.
Hybrid apps use web technologies inside a mobile app.
Cross-platform apps use one codebase for multiple platforms.

## Why Flutter
Flutter allows us to build Android, iOS, web, and desktop apps from one codebase using Dart.
It provides widgets, hot reload, and beautiful UI components.
