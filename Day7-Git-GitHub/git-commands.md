# Git Commands

## Check Git Version

```bash
git --version
```

## Configure Username

```bash
git config --global user.name "Shaik Noore Hafsa"
```

## Configure Email

```bash
git config --global user.email "noorehafsa.shaik@gmail.com"
```

## Initialize Repository

```bash
git init
```

## Check Status

```bash
git status
```

## Stage Files

```bash
git add .
```

## Commit

```bash
git commit -m "Initial Commit"
```

## Connect GitHub

```bash
git remote add origin <repository-url>
```

## Push

```bash
git push -u origin main
```

## Pull

```bash
git pull
```
